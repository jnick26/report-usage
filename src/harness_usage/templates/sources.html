Historical coverage

Availability depends on recoverable local evidence. Recorded tokens, source quantities and API-equivalent estimates are separate; none establishes provider billing or subscription allocation.

Claude Code: qualified modern entries can retain final output counters. Older or unversioned entries may lack final output; provider and recorded USD remain unavailable. Fuller history would require future content-free telemetry or terminal result capture, which is not implemented here.

Copilot in VS Code: core chat history may retain lossy summaries with missing cache, actual-model, failure or credit details. The separate extension transcript is excluded. Complete per-call evidence would require future capture before serialization loses it.

Copilot CLI: supported durable checkpoint and shutdown records retain cumulative usage. Optional schema-8 session-store.db snapshots supply retained per-call lower bounds, reconciled with event summaries without double counting. Add the Copilot home directory to include this database beside session-state; saved roots are not expanded automatically. Older metadata-only sessions have unavailable usage. Database turn summaries are explicitly lossy; native event transcripts take precedence. Future capture is not enabled.

Claude Code and Copilot CLI support is qualified against pinned source contracts and synthetic fixtures, not arbitrary future writer formats or complete historical usage.
